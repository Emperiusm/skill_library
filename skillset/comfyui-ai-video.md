# Skill: AI video generation inside ComfyUI (EXAMPLE)

- **What:** Run video-generation models (Minimax H3, Seedance 2 Fast) as
  ComfyUI custom nodes, so AI shots become repeatable nodes in a graph
  instead of one-off web-UI generations.
- **Pipeline stage:** Marketing / trailer generation (not asset intake).
- **Learned from:** "RESISTANCE | Sci-Fi Short Film" (James Lee's Films),
  r/aivideo, 2026-09-27 run. Minimax H3 run via `@comfyorg` custom nodes;
  Seedance 2 Fast used for a drone-attack shot.
- **Evidence:** The short's breakdown shows keyframed AI shots assembled
  from ComfyUI graphs; prompt writing deliberately kept manual ("prompt
  writing is the directing").
- **Workflow (compressed):** Lock keyframes/concept first → generate shots
  as ComfyUI nodes (repeatable, versioned graphs) → keep prompt writing
  manual → edit and grade in an NLE (Da Vinci Resolve 21 in the source).
- **Principle:** AI shots are directing, not rendering: the graph makes them
  reproducible, the human keeps the decisions.
