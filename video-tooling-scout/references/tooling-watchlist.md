# Tooling watchlist (keep-on-the-side list)
Append-only institutional memory for video-tooling-scout. Never delete an
entry; annotate it instead: ADOPTED / BACKLOGGED / SUPERSEDED / SKIPPED /
WATCH. `bin/trend_watchlist.py` appends "seen again <date>" to reappearing
rows in place; a tool seen three or more times is flagged TRENDING in the run
report.

own list, or keep them marked EXAMPLE until real entries arrive.
